# 📦 השאלה חכמה — מערכת ניהול גמ"ח חפצים

## תיאור
תוכנת ניהול מקצועית לגמ"ח חפצים, כתובה ב-Python עם ממשק גרפי מלא בעברית RTL, עיצוב מודרני (HTML/CSS) בלוח הבקרה ובדוחות, תמיכה בלוח שנה עברי מדויק, ותבניות עיצוב (Light/Dark) להתאמה אישית.

**גרסה נוכחית: 1.5**

---

## 🚀 התקנה והפעלה

### דרישות מקדימות
- **Python 3.10 ומעלה** (הורד מ: https://www.python.org/downloads/)
  - ⚠️ חשוב: בעת ההתקנה סמן **"Add Python to PATH"**
- Windows 10 / 11

### שלבי התקנה
1. **הורד** את כל הקבצים לתיקייה אחת (למשל `C:\HashalaChachama\`)
2. **הפעל** את `התקן_והפעל.bat` (לחיצה כפולה)
   - בפעם הראשונה: מוריד ומתקין את הספריות הנדרשות (~250MB, כולל מנוע תצוגה מבוסס Chromium ללוח הבקרה)
   - בפעמים הבאות: פשוט הפעל `הפעל.bat`

### הפעלה/קומפילציה ידנית (למשתמשים מתקדמים)
אם אתם מעדיפים להפעיל מתוך שורת פקודה (cmd / PowerShell) במקום קבצי ה-bat:
```
cd C:\HashalaChachama
pip install -r requirements.txt
python hashala_chachama.py
```
לבדיקת תקינות התחבירי של הקובץ בלבד (ללא הפעלה בפועל), אפשר להריץ:
```
python -m py_compile hashala_chachama.py
```
פקודה זו תיצור קובץ `.pyc` בתיקיית `__pycache__` ותדפיס שגיאה אם יש בעיה בקוד; אם לא מודפסת שגיאה, הקובץ תקין מבחינה תחבירית.

## ✨ יכולות התוכנה

### 🏠 לוח בקרה
- עיצוב חדש ועדכני (HTML/CSS) עם טבעת סטטיסטיקה חזותית, כרטיסי מידע ניתנים ללחיצה וסקשנים מונפשים
- סטטיסטיקות בזמן אמת: סך חפצים, מושאלים, באיחור, בתיקון
- רשימת חפצים באיחור עם הדגשה באדום
- יומן פעולות אחרונות
- מתאים את עצמו לסכמת הצבעים שנבחרה בהגדרות
- אם לסביבת המחשב חסר מנוע התצוגה הנדרש, התוכנה עוברת אוטומטית לעיצוב הקלאסי (ללא קריסה)

### 📦 ניהול חפצים
- הוספה, עריכה, מחיקה של חפצים
- **הוספת קטגוריות מותאמות אישית** בלחיצת כפתור (בנוסף ל-5 הקטגוריות המובנות: כלי עבודה | ציוד אירועים | מכשירי חשמל | רפואי | שונות)
- **4 סטטוסים**: זמין | מושאל | בתיקון | אבוד
- תמונה לכל חפץ
- מיקום פיזי (מדף/ארון/חדר)
- מספר סידורי / ברקוד
- חיפוש וסינון דינמי, טבלה מיושרת מימין לשמאל במלואה

### 👥 ניהול שואלים
- רשימת שואלים עם פרטי קשר מלאים
- דירוג אמינות (1-5 כוכבים)
- מעקב אחר השאלות פעילות לכל שואל
- חיפוש לפי שם או טלפון

### 📋 ניהול השאלות
- **השאלות פעילות** — עם כפתור החזרה מהיר
- **באיחור** — מסומנות באדום עם ספירת ימי איחור
- **היסטוריה מלאה** — כל ההשאלות מאז הקמת הגמ"ח

### ➕ השאלה חדשה
- בחירת חפץ עם חיפוש חכם (רק חפצים זמינים)
- בחירת שואל עם חיפוש לפי שם/טלפון
- יצירת שואל חדש ישירות מהמסך
- ברירת מחדל: שבוע קדימה, ניתן לשינוי
- נגישה מהסרגל הצדי (לוח בקרה ← השאלה חדשה) או מתוך לוח הבקרה

### 🔔 תזכורות (לשונית נפרדת)
- הגדרות מייל אוטומטי (שרת SMTP, פורט, מייל שולח, App Password) — הועברו ללשונית זו
- קביעת כמה ימים לפני מועד ההחזרה לשלוח תזכורת אוטומטית
- **בדיקת שליחה** — אימות שהפרטים תקינים לפני הפעלה
- **מדריך הגדרה מובנה** — הסבר שלב-אחר-שלב כיצד ליצור App Password ב-Gmail/Outlook/Yahoo
- רשימת כל ההשאלות הפעילות עם כפתור שליחת תזכורת ידנית לכל שואל

### 📅 לוח שנה
- לוח שנה עברי מלא ומדויק (ספריית `pyluach`) עם אפשרות מעבר ללוח לועזי
- תצוגה חזותית של תאריכי השאלה והחזרה, עם סימון ימים עם השאלות פעילות
- לחיצה על תאריך — רואים אילו חפצים מוחזרים/מושאלים
- רשימת החזרות קרובות (7 ימים הבאים)

### 📊 דוחות
- עיצוב חדש מבוסס HTML/CSS עם פס סטטיסטיקות, כפתורי ייצוא בולטים ותרשים פירוט לפי קטגוריה
- **ייצוא Excel** — חפצים, השאלות, שואלים (כולל כותרות בעברית ויישור ימין)
- פירוט לפי קטגוריה: כמה חפצים, כמה זמינים, כמה מושאלים

### ⚙️ הגדרות
- **עיצוב ומראה** — 4 סכמות צבעים מובנות (כחול-זהב, ירוק יערני, אפור-ורוד, מצב כהה), עם תצוגה מקדימה והחלה מיידית על כל התוכנה
- הגדרת לוח שנה (עברי/לועזי)
- מידע על מסד הנתונים וגיבוי לקובץ

## 📚 ספריות וטכנולוגיות

| ספרייה | תפקיד |
|---|---|
| `PySide6` | מנוע הממשק הגרפי (Qt for Python), כולל QtWebEngine ללוח הבקרה והדוחות |
| `pyluach` | חישוב והמרת תאריכים בלוח השנה העברי (גרסה מדויקת, ללא חישובים ידניים) |
| `openpyxl` | ייצוא דוחות לקובצי Excel (xlsx) עם יישור ימין ותמיכה בעברית |

כל הספריות מותקנות אוטומטית בהפעלה הראשונה של `התקן_והפעל.bat`, או באופן ידני דרך `pip install -r requirements.txt`.
